# credit-risk-lab: the fair access study

Three questions from [RESEARCH.md](RESEARCH.md), answered with measured work on the held-out test set (9,000 accounts) using the published champion model. Every number below is generated by `src/study.py` from the run; nothing is typed in.

## 1. Creditworthy rejects

Risk appetite, stated as a rule: Approve every account with PD at or below the threshold where the approved book's observed default rate matches the Stage 1 observed default rate (the lab's performing-book rate) from results/results.json.

- Target approved-book default rate (Stage 1 observed): 12.00%
- Cut-off PD chosen on the test set: 0.2293 (achieved approved-book default rate 12.00%)
- Approved: 6,375 (70.8%); rejected: 2,625
- **Creditworthy rejects: 1,399 of the 2,625 rejected applicants did not default** (53.3% of all rejects; 15.5% of the test set).

These are observed outcomes, not estimates: at this risk appetite the cut-off turns away that many people who, in the event, repaid.

## 2. Thin-file model (behavioural features only)

The champion retrained without the bureau-style fields (excluded: LIMIT_BAL, AGE, SEX, EDUCATION, MARRIAGE, BILL_AMT1..BILL_AMT6, PAY_AMT1..PAY_AMT6). Features kept: utilization, pay_ratio, delinq_mean, delinq_max, bill_trend, dpd_months, PAY_0, PAY_2, PAY_3, PAY_4, PAY_5, PAY_6.

- Thin-file AUC: **0.7687**, against the full model's 0.7810 (gap -0.0123).

Behavioural history alone carries most of the signal. That is the newcomer question in miniature: a thin file is not an empty file when payment behaviour can be observed.

## Limits, on the same page

- The dataset is Taiwan, 2005 (UCI dataset 350), not Canada. Group patterns here demonstrate the audit method; they are not evidence about Canadian borrowers or any Canadian lender.
- Outcomes are a single month (default next month), not lifetime repayment. A 'creditworthy reject' repaid in that window; longer horizons would change some counts.
- The cut-off is set on the same test set it is audited on. A production study would fix the appetite on a validation sample first; the lab states the rule and applies it once, openly.
- AUC is reported per group only where both outcome classes have at least 5 accounts; smaller cells show n/a rather than a noisy number.
