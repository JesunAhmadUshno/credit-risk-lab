# credit-risk-lab

**Question.** At a cut-off that holds the approved book at the
performing-book default rate, how many rejected applicants were
creditworthy, and does a behavioural second look recover them at a
bounded cost?

**Headline.** At that cut-off, 1,218 of 2,386 rejected test applicants (51.0%, 95% bootstrap CI 45.9% to 55.4%) did not default; the registered second look recovered only 10 of them (0.8%), so H1 is refuted.

**Field.** Data analysis. **Job family.** Credit risk modelling and
model validation (data science, risk).

**Verdict.** Functional, not pre-registered. Tests pass in CI, one
command rebuilds every result from the raw data, and the full rebuild
has run end to end (results/run_manifest.json). The hypotheses H1 to
H4 were written before the wave 3 code but after earlier results, so
the repo is capped at Functional (docs/decisions/0002).

Data: UCI "default of credit card clients" (Taiwan, 2005, 30,000
accounts, test set 9,000) and UCI Statlog German Credit (1,000
accounts) as a second population. Public research data, not a
production portfolio. Champion gradient boosting AUC 0.7810 (95% CI
0.7693 to 0.7919).

Live dashboards: https://jesunahmadushno.github.io/credit-risk-lab/lab/
(Lab OS, site/) and https://jesunahmadushno.github.io/credit-risk-lab/
(app, web/).

## Reproduce

```text
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python src/run_all.py
.venv/bin/python -m pytest tests/ -q
```

Python 3.12 (the pins require it). `src/run_all.py` rebuilds every file
in results/ from data/ (about 8 minutes), asserts the headline
invariants and writes results/run_manifest.json. CI runs the same
rebuild and fails if any committed output differs.
